# 跳转与分支

## 消息树

每条会话记录除了消息本身，还带 `id` 与 `parent` 两个字段，把同一会话里的消息串成一棵树。没有回溯过的会话就是一条直链；从某个位置分叉后，同一父节点下面会出现多个子消息。

旧文件里没有这两个字段，读取时按行号补成线性链，所以以前的会话照常打开、照常继续。

## 跳转视图

`/jump` 不接受参数，执行后进入跳转视图：

- 每个节点压成一行，按角色保留底色（用户灰、工具按状态蓝/绿/红、系统通知浅蓝、错误浅红），超出的内容用省略号收起。
- ↑ / ↓ 在消息之间移动，当前选中的那一行整行变明黄底黑字并弹跳一下。
- Enter 跳转，Esc 取消，视图底部是一行按键提示。

## 分支切换

有多个子消息的消息是分叉点，左右两侧各显示一个箭头，← / → 在它的各个分支之间切换。

当前位置停在某个中间消息上时（比如刚跳转过去、还没有发新消息），视图会先展开它最近的一个分支，光标停在原地，箭头用来换到其它分支。如果分叉发生在会话最开始（编辑了第一条用户消息，父节点为空），没有可依附的分叉消息，箭头会显示在根层消息上。

## 跳转语义

| 目标 | 语义 |
| --- | --- |
| 工具调用或助手消息 | 回到该消息刚刚返回的那一刻，聊天记录到它为止，下一条消息从它继续，成为它的子节点 |
| 用户消息 | 回到它的编辑态：聊天记录退到它之前，原文填进输入框并聚焦 |

跳到用户消息后重新发送，新消息与原来的用户消息成为兄弟分支，原消息连同它后面的整条分支都保留在树里，随时可以再 `/jump` 回去。

## 上下文回退

跳转会立即回退模型上下文：sidecar 按跳转点取出从根到该点的历史重建 Agent，下一条请求只会看到这条路径上的消息。

跳转视图只列出落盘的会话记录（用户、助手、工具、错误、模式与工作目录变更），`/info`、`/system` 这类只出现在界面上的瞬时提示不参与跳转；提交跳转后聊天记录会按当前分支重新生成，这些瞬时提示随之消失。

模式是会话级状态，不随分支回退：跳到模式切换之前的位置，当前模式仍是切换后的模式。
